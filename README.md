## 📌 Overview

This repository contains my independent research project on **Explainable Machine Learning for System Log Anomaly Detection** using the Hadoop Distributed File System (HDFS) dataset.

The project investigates the use of **Isolation Forest**, an unsupervised anomaly detection algorithm, together with **SHAP (SHapley Additive Explanations)** to improve the interpretability of anomaly detection in distributed system logs.

This research was conducted as part of my academic portfolio to strengthen my preparation for graduate studies in Artificial Intelligence and the Global Korea Scholarship (GKS) University Track.

---

# 🎯 Research Objectives

- Detect anomalous events within HDFS system logs.
- Apply Isolation Forest for unsupervised anomaly detection.
- Explain anomaly predictions using SHAP.
- Improve transparency and interpretability of machine learning models.
- Develop a reproducible research workflow.

# 📊 Explainability

This project applies **SHAP (SHapley Additive Explanations)** to explain the predictions generated by the Isolation Forest model.

SHAP provides:

- Global feature importance
- Local prediction explanations
- Improved model transparency
